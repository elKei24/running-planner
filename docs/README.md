# Documentation

- [architecture.md](architecture.md) – how the app is put together and why the plan is *derived*, not stored.
- [training-science.md](training-science.md) – the training principles the planner encodes, with sources.
- [decisions/](decisions/) – Architecture Decision Records (ADRs). One file per decision, numbered, never edited after the fact (superseded instead).
- [roadmap.md](roadmap.md) – what each iteration delivered and what is still open.

Conventions: ADRs follow the short Nygard format (Context / Decision / Consequences). Dates are ISO. Keep files in this folder up to date when behaviour changes; the CI does not check them, people do.
